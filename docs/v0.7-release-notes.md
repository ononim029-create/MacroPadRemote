# MacroPad Remote v0.7 preview

This preview bundles the v0.6.2 Windows action hotfix and the next device/profile UX iteration.

## Included

- Fixed Windows x64 SendInput execution with explicit native error reporting.
- Mobile left drawer with profiles, pages and paired computers.
- Phone portrait deck auto-scaling to prevent tile/text overlap.
- Persistent trusted-PC credentials so QR is required for first pairing only.
- Paired device lists on desktop/mobile with quick switching.
- Connection transport moved under Settings (gear) on desktop.
- Profile pages can be created/edited on desktop; mobile is switch-only.
- Improved selected/hover contrast for tabs/page buttons/dropdowns.
- New square sharp-edged mobile application icon aligned with desktop styling.
- Phone UI keeps Deck + Media only; tablet mode is detected for later expansion.
